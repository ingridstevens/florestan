# Demo state for screenshots

`scripts/make-screenshots.sh` runs Florestan on these files instead of your own records, and saves the
README's screenshots to `docs/screenshots`. Every song is by Kevin MacLeod (incompetech.com), released under
Creative Commons Attribution 4.0, from the "Kevin MacLeod Archive" uploads on YouTube, which carry that licence.
The playlist IDs and Apple Music track IDs are made up.
